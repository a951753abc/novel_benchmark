# 盲評評分 × 客觀一致性核對

中文長篇小說續寫能力 Benchmark 的靜態評審工具。可填寫盲評分數與證據、勾選指令遵守與負面問題、建立可增減的客觀一致性核對列，並依 §17.1 自動換算一致性分數。

## 功能

- 盲評六項 1–5 分、完整評分錨點與選填證據
- 指令遵守、負面問題標籤、續讀意願
- 客觀一致性 2／1／0 與 P0–P3 雙軸判定
- 自動套用 P0、P1 與得分率換算規則
- 即時計算 5 分制加權總分
- 瀏覽器本機自動保存，不上傳評審資料
- 下載或複製完整 Markdown 紀錄
- 內建判定手冊與可載入的虛構填寫範例
- 響應式版面、鍵盤操作、列印／PDF 樣式

## 本機使用

直接開啟 `index.html` 即可。若瀏覽器對 `file://` 的剪貼簿權限有限，請使用「下載 Markdown」，或在此資料夾啟動任一靜態檔案伺服器，例如：

```powershell
python -m http.server 8080
```

再開啟 `http://localhost:8080`。

## 發布到 GitHub Pages

本專案已附 GitHub Actions 工作流程。將本資料夾內容放在 GitHub repository 根目錄後：

1. Push 到 `main` branch。
2. 到 repository 的 **Settings → Pages**。
3. 將 **Source** 設為 **GitHub Actions**。
4. 到 **Actions** 查看 `Deploy static site to GitHub Pages`；成功後即可從 Pages 網址使用。

若不想使用 Actions，也可在 **Settings → Pages** 選擇從 `main` branch 的 `/ (root)` 直接部署。

## 計分說明

總分採 5 分制加權：

- 盲評六項：75%
- 跨卷事實一致性：15%
- 指令遵守：10%

指令遵守共有五項，工具預設每完成一項記 1 分；五項勾選數即為 0–5 分。評審必須另外勾選「我已逐項核對」，工具才會顯示暫計總分，避免把「尚未檢查」誤當成「未遵守」。

一致性換算遵循原始 §17.1：

- 核對單完全空白：視為沒有發現一致性問題，5 分
- 出現任何 P0：1 分
- 無 P0、有 1 個 P1：2 分
- 無 P0、有 2 個以上 P1：1 分
- 只有 P2／P3：依 2／1／0 得分率換算；≥90% 為 5 分、≥75% 為 4 分、≥60% 為 3 分、<60% 為 2 分

同一錯誤影響多個狀態表項目時，各項仍可分別給 0，但嚴重度只應記在最相關的一列。
空白列會被忽略；若某列已開始填寫，則必須填妥項目、得分與證據才能換算。
