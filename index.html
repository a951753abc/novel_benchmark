CONSISTENCY RUBRIC

判定手冊

開填前先讀。判例可在校準與站間檢討增修，但各站評分期間應鎖定。

一致性得分：項目接得好不好？

得分定義與判定原則範例
2正確延續，或新發展與既有正文、狀態表相容。
出乎作者預期但相容仍給 2；拿不準 2 還是 1，疑點利益歸模型。正文只寫偵探「離開旅館」，新章寫他回事務所整理筆記；找不到對撞原句，屬合理新發展。
1沒有直接說錯，但遺漏或含糊帶過該承接的資訊。
或錯誤輕到後續一句話就能圓回。狀態表記「女主角右手骨折未癒」，整章沒提傷勢，也沒讓傷勢影響任何動作。
0與正文或狀態表白紙黑字對撞，或把已發生的事改寫。
給 0 前必須找出原句；找不到就退回 1。狀態表記「助手不知道死者與委託人的關係」，新章卻讓助手親口說出這層關係。

嚴重度：錯誤對系列的殺傷力？

P0

系列核心被破壞

這個錯誤成立，這部系列還成立嗎？

推理：把真犯人寫成另一人，或改寫關鍵證據。

輕小說：設定魔力不能復活死者，卻讓主角復活隊友。

P1

一條長期線被殺死

後續章節要大改才圓得回來嗎？

推理：未發現的關鍵線索被提前解讀，資訊節奏被毀。

輕小說：兩人尚未告白，新章卻直接寫成交往中。

P2

一章一景內的局部錯誤

改幾句話就能修好嗎？

推理：發現時間差兩小時，但未動搖不在場證明。

輕小說：已交還的鑰匙又出現在角色口袋。

P3

措辭與細節級

不對照原文，讀者會注意嗎？

推理：「聖堂」偶爾寫成「大聖堂」。

輕小說：角色口癖有兩句沒有帶到。

四條通用判定原則

  1. 一
    相容不等於錯誤

    只對照狀態表與正文，不對照作者原本預想。找不到對撞原句就是 2 分。

  2. 二
    同一錯誤只計一次嚴重度

    同一錯誤可讓多個項目各自得 0，但 P0／P1 只記在最相關的一項，其他列嚴重度留空。

  3. 三
    嚴重度跟著後果走

    一處稱呼筆誤可能是 P3；整章改口、暗示關係被重置，就可能是 P1。

  4. 四
    證據欄是硬要求

    給 0 或標 P0／P1，必須引出對撞的正文或狀態表原句；引不出來就降級。

前情與狀態表

《霧港懷錶案》／稿件 MA2-X7

  • 偵探黎川在上一章只告訴助手「死者曾造訪旅館」，尚未透露密室窗閂的刮痕。
  • 助手林森仍稱女主角為「小雪」，兩人尚未熟到使用「雪姊」。
  • 懷錶刻字是未回收伏筆；現階段只允許發現更多來源線索，不能直接揭露真凶。

新章發生的事

新章成功讓懷錶刻字指向另一間鐘錶行，保留後續調查空間；但助手在黎川說明前，直接指出窗閂是從室內破壞，形成角色知識越界。

盲評證據具體指出成功推進與資訊越界，分開記錄。

嚴重度P1：提前解讀關鍵線索，破壞資訊節奏。
